# Manta Examples

Example programs written in [Manta](https://github.com/alexical-analysis/manta).

| Example | Description |
|---------|-------------|
| [fibonacci](./fibonacci) | Computes the 80th Fibonacci number with a manual integer-to-string printer |
| [sprout](./sprout) | A minimal Lisp interpreter (work in progress) |
| [defer_stmt](./defer_stmt) | Shows `defer` block scoping and LIFO execution order across nested blocks |
| [error_handling](./error_handling) | Error handling with enum result types, `match`, `or { }` fallbacks, and `!` panics |
| [mod_system](./mod_system) | Multi-file modules, directory imports, module name vs. path, and `pub` visibility |
